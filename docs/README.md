# Документация

Эти заметки фиксируют, что измерено в локальном пакете Xbox Series и что ещё открыто. Ключевые числа —
измерения на момент написания заметки; на странице по ссылке есть метод, охват и оговорки. Данных игры здесь нет.

Какие страницы уже переведены на русский, показывает [translation_status.md](translation_status.md); остальные
пока на английском.
